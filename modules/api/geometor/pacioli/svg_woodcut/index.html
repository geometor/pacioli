geometor.pacioli.svg_woodcut¶

Deterministic .euclid-graphic SVG generator for Pacioli’s Summa (1494) codex.

Generates nine theme-adaptive, interactive .euclid-graphic SVGs directly from exact SymPy and geometor.model coordinates (converting symbolic expressions to pixel coordinates strictly at SVG serialization time). Every generated SVG adheres to the photon-platform/publish five-layer contract (#elements, #graphics, #highlights, #points, #labels), 3-vertex midpoint segment paths for congruence tick markers (#geom-tick-1..3), and canonical data-ref wiring for :g: and :eq: interactive highlighting.
