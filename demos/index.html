Symbolic Demonstrations¶

Executable Python 3.13 CLI demonstrations backed by sympy and geometor.model for Fra Luca Pacioli's Summa de arithmetica, geometria, proportioni et proportionalita (Venice, 1494) and De Divina Proportione (Venice, 1509).

Run any demonstration inside the offline uv environment:

uv run --no-sync python demos/summa_proportions.py
        uv run --no-sync python demos/summa_geometria.py
        uv run --no-sync python demos/summa_quaderno.py

Runnable Demonstrations

  • Proportioni & Regola dela Cosa (1494)
  • Tractatus Geometriae (Part II, 1494)
  • De Computis et Scripturis & Problem of Points (1494)
  • Master Demonstration Runner
